# ShopEase – Full Stack E-Commerce Website

ShopEase is a full-stack e-commerce web application built using JavaScript and Next.js.

## Tech Stack

- JavaScript
- Next.js
- React.js
- Tailwind CSS
- Node.js
- MongoDB

## Features

- User Registration and Login
- Forgot Password and OTP Verification
- User Profile Management
- Product Listing
- Shopping Cart
- Checkout and Order Placement
- My Orders and Order Details
- Admin Login and Dashboard
- Admin Order Management

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```
